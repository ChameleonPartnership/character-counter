SMS Marketing: How Character Limits Affect Deliverability and Cost

Published 1 September 2026. Updated 1 September 2026. 6 min read.

SMS is the place where character count most obviously affects money. A message that crosses a segment boundary can cost more to send. A message that uses emoji or certain symbols can move to a different encoding. A message that hides the action after a long greeting can lose replies.

Understand the 160-character segment

The classic SMS limit is 160 characters for messages using the GSM character set. Longer messages are split into segments and reassembled on the recipient phone. Sending platforms usually show the segment count, and marketers should treat that count as part of sign-off.

Unicode characters, including many emoji and some curly punctuation, can reduce the number of characters available in a single segment. That does not mean you should never use them. It means the final message must be tested in the actual sending tool before launch.

A privacy-first character counter is useful for drafting because campaign copy may include discount codes, unreleased offers or customer segments. Use it for early edits, then confirm encoding and billing in your SMS platform.

Put the action before the conditions

SMS readers decide quickly. Start with the useful action: "Use code SEPT20 by Friday" or "Your appointment is at 14:30". Put terms, links and sender details after the core message. If the first 60 characters are slow, the message feels expensive and unclear.

Weak example: "We wanted to remind you that our seasonal sale is currently live and you can receive a discount when you shop online." Better: "Save 20% online with code SEPT20. Ends Friday." The shorter version states the offer, channel, code and deadline in 47 characters.

For appointment reminders, include the date, time and required action. "Dentist appointment: 10 Sept, 09:30. Reply C to confirm." is more useful than a polite paragraph. It also leaves room for the clinic name if required.

Count compliance text early

Marketing SMS often needs opt-out wording, sender identification or legal text. Do not add that after the creative line is approved. Count it from the start. A 125-character offer becomes a two-segment message very quickly once "Reply STOP to opt out" and a tracked link are added.

Links should be treated as variable. A short test link in a document may become a longer tracked link at send time. Ask for the final link format before approval, or reserve a character budget for it. This avoids a late rewrite under time pressure.

If a campaign needs personalisation, test the longest likely value. "Hi Jo" and "Hi Christopher" have different counts. A city name, product name or appointment type can push a message across a boundary.

Approval checklist for SMS

Send the final approval message with four numbers: character count, segment count, link length and longest personalisation example. That gives the approver the commercial and editorial context. It also creates a record if costs change after late edits.

Keep a one-segment fallback version. If the primary message uses two segments because the offer needs detail, a shorter fallback protects the campaign if budget changes. Write that fallback before launch week.

SMS is unforgiving because it is short, personal and paid by volume. Character counting is not admin. It is part of cost control and reader respect.

  • Draft with the offer, code and deadline first.
  • Add opt-out wording before sign-off.
  • Test emoji and special symbols in the sending platform.
  • Check the longest personalised version, not only the average one.

Before and after SMS examples

Weak reminder: "Hello, this is a friendly reminder that you have an appointment booked with our team tomorrow afternoon and we would appreciate it if you could confirm." Better reminder: "Appointment tomorrow at 14:30. Reply C to confirm or call us to change it." The better version gives the time, action and fallback.

Weak offer: "Our summer promotion is available now and customers can use the following code to get a saving on selected products online." Better offer: "Save 15% online with code SUMMER15. Selected items. Ends Sunday." The shorter version keeps the commercial facts and removes the announcement frame.

Weak delivery update: "We wanted to let you know that your order has now been dispatched and should arrive with you soon." Better update: "Order dispatched. Track delivery: [link]." The final link length determines whether more detail fits.

Measure cost before creative sign-off

SMS budget is usually approved before the final words are approved. That creates risk. If the creative line crosses from one segment to two after tracking links, opt-out text and personalisation are added, the media cost can change while everyone thinks the campaign is finished.

Build a cost check into the copy document. Include the audience size, expected segment count and final count. A one-character overrun can be harmless in a social post and expensive in a large SMS send. The count belongs beside the copy, not hidden inside the sending tool at the end.

If the message must use two segments, make that a deliberate choice. Sometimes clarity, compliance or revenue justifies the extra segment. What matters is that the team chooses it knowingly.

A useful SMS copy brief

Brief SMS copy with the required sender name, offer, deadline, link format, opt-out wording and personalisation fields. Give the writer the target segment count at the start. Without those details, the first draft will often look good and fail once the operational text is added.

For regulated or high-volume sends, ask compliance and CRM teams to review the same counted version. Everyone should be looking at the message that will actually be sent, not an early creative draft.
